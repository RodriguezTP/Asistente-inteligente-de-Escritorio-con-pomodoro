# Asistente-inteligente-de-Escritorio-con-pomodoro
El proyecto se basa en un asistente de escritorio, el cual ayuda a optimizar el tiempo para realizar ciertas tareas en cierto tiempo usando como base la tecnica de pomodoro, un agente inteligente reparte el tiempo y da recomendaciones de descanso, además de que cuenta con actuadores de iluminación y ventilación
